# Sample: Widget SaaS path

Wedge now: ship a Mac menu-bar widget that lists the user’s last 5 documents and opens the most recent on click. Works offline.

Then: generative chips to approve/reject AI edits; computer-use loop where an LLM plans and a second system picks click/type; multi-agent traffic when ten bots collide.

Non-goals: replacing the user’s chat LLM; building a form builder; tutorial-hosting business.

North star: Mac control plane for agent runs.
